## 과제: QT 주제 우선순위 결정 알고리즘 설계

사용자가 온보딩에서 다음 정보를 제공합니다:
- 신앙 성숙도: 입문/초급/중급/심화
- 선택한 관심 주제: 140개 중 복수 선택 (예: ["불안", "용서", "감사", "직장 생활", "기도"])
- 묵상 분량: 짧음(5분)/보통(10분)/많음(20분+)

이 정보를 바탕으로, 선택된 주제들의 **진행 순서**를 자동 결정하는 알고리즘을 설계해주세요.

## 제약 조건

1. 각 주제는 7개 카테고리 중 하나에 속함:
   감정/내면, 삶의 상황, 관계, 신앙 성장, 성품/덕목, 신학/교리, 생활

2. 영적 성장의 일반적 흐름:
   - 치유(감정) → 회복(관계) → 성장(신앙) → 성숙(성품) → 사명(생활)
   - 하지만 위기 상황(삶의 상황)은 항상 최우선

3. 성숙도별 차이:
   - 입문: 감정/내면 주제를 먼저 → 신학/교리는 나중에
   - 심화: 신학/교리나 생활 주제도 바로 시작 가능

4. 같은 카테고리 주제가 연속되면 지루할 수 있음 → 적절히 섞어야 함

## 요구 사항

1. 우선순위 점수 산출 공식을 만들어주세요
   - 입력: (주제명, 카테고리, 성숙도, 선택 순서)
   - 출력: 우선순위 점수 (높을수록 먼저)

2. 카테고리별 기본 우선순위 가중치 테이블 (성숙도 4단계별로 다르게)

3. 연속 방지 규칙 (같은 카테고리 연속 금지, 무거운 주제 연속 금지 등)

4. 엣지 케이스 처리:
   - 1개만 선택한 경우
   - 10개 선택한 경우
   - 같은 카테고리에서 5개 선택한 경우
   - 위기 주제(자살충동, 중독 등)가 포함된 경우

5. 최종 결과를 의사코드(pseudocode)로 작성해주세요

### 1. 예시 입력/출력에 대한 논리적 추론 및 평가

> **입력:** 성숙도=초급, 주제=["불안", "감사", "부부갈등", "기도", "직장생활"]  
> **기대 출력:** ["불안", "기도", "부부갈등", "감사", "직장생활"]

**전문가 평가: 제시해주신 기대 출력은 목회 상담학과 기독교 교육학 관점에서 '완벽에 가까운 최적의 순서'입니다.** 

단순히 영적 성장의 기본 흐름(감정→관계→신앙)만 기계적으로 따르면 `[불안 → 부부갈등 → 기도]` 순서가 되어야 합니다. 하지만 "불안(감정)"과 "부부갈등(관계)"은 둘 다 감정적 에너지를 크게 소모하는 **'무거운(Heavy) 주제'**입니다. 초급자가 이를 연달아 직면하면 영적 소진(Burnout)이 올 수 있습니다. 

따라서 다음과 같은 **'영적 호흡(Spiritual Pacing)'**의 큐레이션이 가장 이상적입니다.
1. **1일차 (불안):** 내면의 고통을 공감받고 상처를 직면하는 **치유**
2. **2일차 (기도):** 현실의 어려운 문제에 맞서기 전, 하나님과 소통하며 에너지를 얻는 **영적 환기(Breathing)**
3. **3일차 (부부갈등):** 기도로 얻은 영적 힘을 바탕으로 수평적 **관계 회복** 시도
4. **4일차 (감사):** 갈등을 극복하며 내면에 긍정적 변화가 일어나는 **성품**의 열매
5. **5일차 (직장생활):** 내면과 관계가 모두 정돈된 후 세상으로 나아가는 **사명**

아래 설계된 알고리즘은 '무거운 주제 연속 방지'라는 수학적 페널티 공식을 통해 이 완벽한 흐름을 정확하게 자동 도출해냅니다.

영적 성장 5단계 흐름을 뼈대로 하되, 성숙도(4단계)에 따라 영적 소화력이 다르므로 가중치(100점 만점)의 무게중심을 다르게 배정합니다.

| 카테고리 (분류) | 입문 | 초급 | 중급 | 심화 | 기독교 교육학적 설계 의도 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **0. 삶의 상황(위기)**| 100 | 100 | 100 | 100 | 고난/위기 상황은 성숙도 불문 최우선 처방 |
| **1. 감정/내면** | **90** | **85** | 70 | 60 | 초신자일수록 교리적 가르침보다 정서적 공감이 선행되어야 함 |
| **2. 관계** | 80 | 80 | 75 | 70 | 내면이 안정된 후 타인과의 수평적 갈등 회복으로 나아감 |
| **3. 신앙 성장** | 60 | 75 | **85** | 80 | 초~중급 단계에서 영적 기초(말씀, 기도)를 단단히 세움 |
| **4. 성품/덕목** | 50 | 65 | 80 | **85** | 신앙이 내재화되어 인격적 열매를 맺는 성화의 과정 |
| **5. 생활 (사명)** | 40 | 55 | 70 | **90** | 신앙을 세상을 향해 실천하는 단계. 심화될수록 비중 증가 |
| **6. 신학/교리** | 20 | 40 | 65 | **95** | 입문자에겐 무거우나 심화자에게는 흔들리지 않는 영적 뼈대 |

### 3. 우선순위 점수 산출 공식 및 연속 방지 규칙

알고리즘은 변하지 않는 **'초기 점수'**를 부여한 뒤, 다음 날짜 묵상을 고를 때마다 변하는 **'동적 점수'**로 순서를 결정합니다.

**A. 초기 점수 (Initial Score)**
> **$Score_{init} = W_{base} + B_{order} + B_{crisis}$**
*   **$W_{base}$**: 위 테이블의 성숙도별 카테고리 점수
*   **$B_{order}$ (선택 순서 보너스)**: 사용자가 무의식적으로 먼저 누른 주제가 가장 갈급한 고민일 확률이 높음. `(총 선택 개수 - 인덱스) * 2점` 
*   **$B_{crisis}$ (위기 보너스)**: 주제 메타데이터에 `is_crisis = True` (자살충동, 중독, 파산 등)가 있으면 **+1000점** 부여.

**B. 동적 점수 산출 (Dynamic Penalty System - 연속 방지 규칙)**
> **$Score_{dynamic} = Score_{init} - P_{category} - P_{heavy}$**

남은 주제들을 평가할 때 **'직전에 배치된 주제의 속성'**을 기준으로 페널티를 부여합니다.
1. **$P_{category}$ (동일 카테고리 연속 방지):** 직전 주제와 카테고리가 같다면 **-30점**.
2. **$P_{heavy}$ (무거운 주제 연속 방지):** 모든 140개 주제에 `is_heavy` 속성(감정/인지 소모가 큰 주제. 예: 불안, 이혼, 깊은 교리)을 둡니다. 직전 주제가 `Heavy`였는데 다음 후보도 `Heavy`라면 **묵상 분량에 따라 차등 페널티**를 줍니다.
   - 묵상 분량 **짧음(5분)**: 페널티 **-40점** (연달아 소화 불가)
   - 묵상 분량 **보통(10분)**: 페널티 **-20점**
   - 묵상 분량 **많음(20분+)**: 페널티 **-5점** (깊은 연속 묵상 감당 가능)

### 4. 엣지 케이스 처리 방안

1. **1개만 선택한 경우**: 계산 연산을 생략하고 즉시 해당 묵상을 제공합니다(`O(1)`). 해당 QT 완료 후 "다음 단계 추천 시스템"을 띄워 영적 확장을 유도합니다.
2. **10개를 선택한 경우**: 알고리즘이 완벽하게 작동하여 `[감정(Heavy) → 신앙(Light) → 관계(Heavy) → 성품(Light)...]` 식으로 10일간 지루함 없이 리듬감 있게 셔플링합니다.
3. **같은 카테고리에서 5개 선택한 경우**: 모두 동일한 $P_{category}$ 페널티를 받아 점수 격차가 상쇄됩니다. 결국 선택 순서대로 5일이 꽉 차게 되는데, 영적 피로를 막기 위해 **시스템이 강제로 3일 차에 타 카테고리의 '환기용 브릿지 주제'(예: 위로의 시편 등)를 1개 삽입**하여 숨 고르기를 유도합니다.
4. **위기 주제가 포함된 경우**: 초기 점수에 부여된 +1000점으로 인해 어떠한 페널티를 받아도 압도적 1위를 유지합니다. 즉각적인 영적 처방을 위해 무조건 1일 차(최우선)에 배치됩니다.

### 5. 최종 알고리즘 의사코드 (Pseudocode)

```python
# 상수 및 가중치 테이블 정의
WEIGHT_TABLE = { ... } # 위의 2번 표 데이터

def generate_qt_curriculum(maturity, duration, selected_topics):
    N = len(selected_topics)
    if N <= 1:
        return selected_topics

    # 1. 초기 점수 산출 (Initial Scoring)
    for i, topic in enumerate(selected_topics):
        base_score = WEIGHT_TABLE[maturity][topic.category]
        order_bonus = (N - i) * 2
        crisis_bonus = 1000 if topic.is_crisis else 0
        topic.initial_score = base_score + order_bonus + crisis_bonus

    curriculum = []
    remaining = selected_topics.copy()
    
    # 엣지 케이스 판별 (단일 카테고리 다수 선택 여부)
    unique_categories = set(t.category for t in remaining)
    is_monotone = (len(unique_categories) == 1 and N >= 4)
    
    prev_topic = None

    # 2. 동적 스케줄링 루프 (Dynamic Scheduling)
    while len(remaining) > 0:
        for topic in remaining:
            topic.dynamic_score = topic.initial_score
            
            if prev_topic:
                # 규칙 1: 카테고리 연속 방지
                if topic.category == prev_topic.category:
                    topic.dynamic_score -= 30
                    
                # 규칙 2: 무거운 주제 연속 방지 (분량 연동)
                if prev_topic.is_heavy and topic.is_heavy:
                    if duration == "짧음":
                        topic.dynamic_score -= 40
                    elif duration == "보통":
                        topic.dynamic_score -= 20
                    elif duration == "많음":
                        topic.dynamic_score -= 5
                        
        # 동적 점수가 가장 높은 주제를 추출하여 커리큘럼에 추가
        remaining.sort(key=lambda x: x.dynamic_score, reverse=True)
        best_topic = remaining.pop(0)
        curriculum.append(best_topic)
        
        prev_topic = best_topic

    # 단일 카테고리 쏠림 현상 시 숨고르기(Breather) 강제 삽입
    if is_monotone and len(curriculum) >= 3:
        breather_topic = get_system_breather_topic(maturity)
        curriculum.insert(2, breather_topic) # 3일 차에 환기용 주제 삽입

    return curriculum
```

**💡 [알고리즘 연산 증명] 예시 입력에 코드를 대입해 보면:**
1. **1일차 계산**: 불안(95점), 부부갈등(86점), 기도(79점)... → `[불안]` 선택 (Heavy)
2. **2일차 계산**: 직전이 `불안(Heavy)`이므로 `부부갈등(Heavy)`은 페널티(-20점)를 받아 66점으로 추락. 반면 `기도(Light)`는 페널티 없이 79점 유지 → `[기도]` 선택 (Light)
3. **3일차 계산**: 직전이 Light이므로 페널티 없음. 부부갈등 본래 점수 86점으로 복귀 → `[부부갈등]` 선택 (Heavy)

이처럼 동적 페널티 알고리즘을 통해 앞서 1번에서 극찬했던 **`[불안 → 기도 → 부부갈등 → 감사 → 직장생활]`**의 기독교 교육학적 황금 배치가 수학적으로 완벽하게 도출됩니다.

### 1. 동점 처리: 안정 정렬(Stable Sort)만으로 충분한가?

**결론부터 말씀드리면, 안정 정렬만으로는 부족합니다.** 
`dynamic_score`가 완전히 동일한 동점 상황이야말로 알고리즘이 **'영적 페이스메이커(Pacemaker)'**로서 적극적으로 개입할 수 있는 절호의 기회입니다. 단순 안정 정렬(선택 순서)에 의존하기보다, 다음과 같은 **다중 조건 정렬(Multi-key Sort) 타이브레이커**를 적용해야 합니다.

*   **1순위 (`dynamic_score`):** 동적 점수 내림차순
*   **2순위 (영적 환기 우대):** 직전 묵상이 `Heavy`였다면, 동점 후보 중 무조건 **`Light` (is_heavy=False) 주제를 우선 배치**. (가장 중요한 영적 피로도 관리 장치)
*   **3순위 (발달 단계 우선도):** 기독교 교육의 자연스러운 발달 순서인 `[1.감정 → 2.관계 → 3.신앙 → 4.성품 → 5.생활 → 6.신학]` 순서가 앞서는 것을 우선. (위기 상황은 무조건 최우선)
*   **4순위 (사용자 선택 순서):** 여기까지 동점일 때 비로소 안정 정렬(사용자가 온보딩에서 먼저 클릭한 순서)을 적용하여 갈급함을 존중.

**💻 정렬 로직 의사코드(Python):**
```python
# 카테고리 발달 순서 가중치 (작을수록 우선)
CAT_ORDER = {"상황(위기)":0, "감정":1, "관계":2, "신앙":3, "성품":4, "생활":5, "신학":6}

remaining.sort(key=lambda x: (
    -x.dynamic_score,  # 1순위: 점수 높은 순
    -1 if (prev_topic and prev_topic.is_heavy and not x.is_heavy) else 0, # 2순위: 직전이 Heavy면 Light 우대
    CAT_ORDER[x.category], # 3순위: 발달 순서가 앞선 카테고리
    x.selection_index      # 4순위: 온보딩에서 먼저 누른 순서
))
```

### 3. 같은 주제 재방문: 입문자의 '불안' vs 심화자의 '불안'

        *   *입문 (위로/수용):* "오늘 하나님이 당신의 불안을 어떻게 안아주시나요?"

### 4. `is_heavy` 140개 주제 분류 가이드 (에너지 소모 기준)

`is_heavy`의 판별 기준은 **"묵상 시 과거의 상처를 들추어내어 아프거나(감정적 트리거), 고도의 지적/영적 결단이 필요하여 에너지가 크게 방전되는가?"** 입니다. 
반면 `Light`는 읽으면서 에너지가 채워지거나 일상에서 가볍게 적용할 수 있는 환기용 주제입니다. 각 카테고리별 대표적인 분류 예시입니다.

#### 🔴 HEAVY (에너지 소모가 큼 / 연속 시 페널티 적용)
*   **0. 삶의 상황(위기):** *(대부분 Heavy)* 사별, 이혼, 파산/심각한 빚, 암/난치병 투병, 실직 장기화, 자살 충동, 가정 폭력, 난임/불임
*   **1. 감정/내면:** 심한 우울, 공황/깊은 불안, 극심한 분노, 깊은 열등감, 죄책감/정죄감, 수치심, 과거의 상처(트라우마)
*   **2. 관계:** 부부 갈등(위기), 부모에 대한 원망, 자녀의 탈선, 고부/장서 극심한 갈등, 직장 내 괴롭힘, 배신, 이단에 빠진 가족
*   **3. 신앙 성장:** 영적 침체(광야), 치열한 영적 전쟁, 의심과 회의감, 죄의 유혹, 중독 끊기(포르노/알코올), 금식과 철야, 철저한 회개
*   **4. 성품/덕목:** 자아 부인(십자가 지기), 탐심 내려놓기, 교만 꺾기, 뼈를 깎는 인내, 원수 사랑, 불이익을 감수하는 정직, 순결 유지
*   **5. 신학/교리:** 고난의 이유(신정론), 예정과 자유의지, 종말론/요한계시록, 지옥과 최후의 심판, 원죄, 이단/사이비 분별
*   **6. 생활/사명:** 생명윤리(낙태 등), 동성애/젠더 이슈, 비윤리적 지시 대처(직장 비리), 정치적 이념과 신앙의 충돌, 치열한 입시/경쟁 압박

#### 🟢 LIGHT (에너지를 채워주거나 환기함 / 브릿지 역할)
*   **0. 삶의 상황(변화):** 이사/환경 변화, 진로 변경, 결혼 준비, 임신/출산의 기쁨, 새 출발, 졸업/입학, 은퇴 후의 삶 기대
*   **1. 감정/내면:** 일상의 소소한 감사, 평안, 기쁨, 하나님의 위로, 자존감 회복, 소망, 자족하는 마음, 정서적 쉼(휴식)
*   **2. 관계:** 좋은 친구 우정, 부부의 친밀함, 자녀 축복하기, 부모 공경, 이웃 환대와 섬김, 성도의 교제(셀/소그룹), 격려와 칭찬
*   **3. 신앙 성장:** 아침 묵상(QT), 일상 기도, 찬양의 기쁨, 성경 통독, 주일 성수, 예배의 감격, 감사 일기 쓰기, 믿음의 선진들 묵상
*   **4. 성품/덕목:** 온유, 겸손, 성실, 친절, 긍휼과 자비, 지혜, 용기, 책임감, 유머와 여유, 화평을 만드는 자
*   **5. 신학/교리:** 하나님의 무조건적 사랑, 천국의 소망, 창조 세계의 아름다움, 임마누엘(동행하심), 구원의 확신, 예수님의 생애
*   **6. 생활/사명:** 시간 관리, 건전한 취미와 신앙, 건강/운동(성전된 몸 돌보기), 피조세계(환경) 돌봄, 이웃 구제/기부, 선한 언어 생활

**💡 알고리즘 작동 요약:** 
실제 앱에서 위기에 처한 유저가 `[우울(H), 이혼(H), 파산(H), 평안(L), 기도(L)]`를 선택했다면, 알고리즘은 앞선 동적 점수 체계에 따라 **`우울(H) → 평안(L) → 이혼(H) → 기도(L) → 파산(H)`** 순서로 텐션을 자동 조절합니다. 사용자는 앱을 쓰면서 "마치 내 마음을 읽고 완급을 조절해 주는 지혜로운 목회자"를 만난 것 같은 감동을 경험하게 될 것입니다.

### 5. 복수 주제 인터리빙(Interleaving)과 브릿지 알고리즘

3개 주제(예: 불안, 기도, 부부갈등)를 하루 단위로 교차(Day 1: 불안 → Day 2: 기도 → Day 3: 부부갈등)하는 것은 인지적 전환 비용(Cognitive Switching Cost)을 발생시켜 깊은 묵상(Lectio Divina)을 방해하고 **'영적 멀미(Spiritual Whiplash)'**를 초래합니다. 

따라서 **[마이크로 블록(Micro-block) 인터리빙]**과 **[의미론적 브릿지(Semantic Bridge)]**의 결합을 제안합니다.

#### A. 마이크로 블록 인터리빙 알고리즘
주제를 1일 단위가 아니라 **3일 단위의 '작은 호흡'으로 묶어서 교차**합니다. (한국 교회의 전통적인 특새/부흥회 호흡이자, 인지적으로 하나의 주제를 소화하기에 가장 적합한 단위입니다.)

*   **블록 1:** `[Day 1~3] 주제 A 집중 (예: 불안)`
*   **전환일:** `[Day 4] 브릿지 구절`
*   **블록 2:** `[Day 5~7] 주제 B 집중 (예: 기도)`
*   **전환일:** `[Day 8] 브릿지 구절`
*   **블록 3:** `[Day 9~11] 주제 C 집중 (예: 부부갈등)`
*   *(이후 다시 주제 A의 Day 4~6으로 순환)*

#### B. 브릿지 구절(Bridge Verse) 매칭 알고리즘
주제가 급격히 바뀔 때, 뜬금없는 전환이 되지 않도록 뇌와 영혼에 '징검다리'를 놓아주는 2가지 브릿지 로직을 구현합니다.

**① 교집합 브릿지 (Intersection Bridge)**
*   **상황:** 연관된 두 주제가 전환될 때 (예: 불안 → 기도)
*   **로직:** 모든 묵상 DB에 해시태그를 달아두고, 전환되는 두 주제의 교집합 태그(예: `#하나님의_주권`, `#평안`)를 가진 독립된 구절을 추출.
*   **가이드 멘트 자동생성:** "지난 3일간 우리는 요동치는 내면의 **[불안]**을 직면했습니다. 이제 그 마음을 있는 그대로 안고, 하나님과 대화하는 **[기도]**의 자리로 나아가려 합니다. 두 마음을 잇는 시편 62편을 묵상해 봅시다."

**② 안식 완충 브릿지 (Sabbath Buffer Bridge)**
*   **상황:** `Heavy` 주제에서 또 다른 `Heavy` 주제로 넘어갈 때 (예: 우울 → 부부갈등)
*   **로직:** 교집합 태그를 찾지 않고, 무조건 **'은혜/안식 특화 구절(시편 23편, 마태복음 11장 등)'**을 강제 처방하여 영적 화상(Burnout)을 방지.
*   **가이드 멘트:** "무거운 마음의 짐을 다루느라 수고하셨습니다. 내일 새로운 삶의 갈등을 다루기 전, 오늘은 아무것도 하지 말고 그저 우리를 쉬게 하시는 하나님의 품(안식)을 누리십시오."

### 6. 장기 사용자의 1년 영적 여정 (1-Year Spiritual Journey)

신앙은 단거리 스프린트가 아니라 마라톤입니다. 기독교 고전 영성학의 발달 단계인 **'정화(치유) → 조명(훈련) → 일치(사명)'**의 뼈대를 현대적으로 적용하여 4분기 로드맵을 설계합니다.

#### 🍂 Month 1-3: 해갈과 정착 (Focus on "ME" & Felt Needs)
*   **목표:** 당면한 고통 해결 및 매일 QT 습관(리텐션) 형성
*   **콘텐츠:** 온보딩에서 사용자가 직접 선택한 갈급한 주제들 위주 (주로 위기상황, 감정 카테고리).
*   **가이드 톤앤매너:** 철저히 '공감, 위로, 수용, 지지'. 정답을 강요하지 않음.
*   **M3 완료 마일스톤 (100일 축하 리포트):** 
    *   *액션:* 100일 달성 시 초기 회고 리포트 제공.
    *   *메시지:* "지난 3개월간 하나님 앞에서 '불안'을 참 많이 다루셨네요. 처음 이곳에 오셨을 때보다 마음이 조금 가벼워지셨나요?"

#### 🌱 Month 4-6: 기초 뼈대 세우기 (Focus on "GOD" & Foundation)
*   **목표:** 문제 해결적 신앙에서 '하나님 중심적 신앙'으로 시선 이동, 영적 편식 교정
*   **콘텐츠 (시스템 개입 - Nudge):** 급한 불(감정)을 껐으므로, 사용자가 고르지 않았더라도 시스템이 주도적으로 **[신앙 기초 경로: 말씀/기도/구원의 확신/예배]**를 추천 1순위에 올립니다.
*   **M6 완료 마일스톤 (하프타임 & 레벨업 제안):** 
    *   *액션:* 성숙도 상승 제안 (입문 → 초급/중급). 
    *   *메시지:* "축하합니다! 매일 말씀과 동행하며 영적 근육이 제법 단단해졌습니다. 내일부터는 묵상의 깊이를 [초급]으로 올려 더 깊은 우물을 파보시겠어요?"

#### 🌿 Month 7-9: 직면과 심화 (Focus on "INNER CORE" & Sanctification)
*   **목표:** 성화(Sanctification) 및 불편한 자아 대면
*   **콘텐츠 (재방문 개입 - Revisit):** 1분기에 다루었던 주제(예: 불안)를 시스템이 **'심화(Advanced) 버전'으로 다시 꺼내옵니다.**
    *   *가이드 멘트:* "7개월 전, 우리는 불안의 표면을 만지며 위로받았습니다. 그동안 당신은 참 많이 성장했습니다. 이제 한층 성숙해진 시선으로, 내 불안의 깊은 뿌리(하나님보다 의지하는 우상)를 말씀으로 직면해 볼 시간입니다."
*   **추가 오픈:** 성숙도가 올랐으므로 가려두었던 무거운 덕목(교만 꺾기, 십자가 지기, 철저한 용서)을 전면에 노출합니다.

#### 🍎 Month 10-12: 사명과 흘려보냄 (Focus on "WORLD" & Mission)
*   **목표:** 내면의 평안을 넘어 일터와 가정, 세상 속에서 그리스도인으로 살아가기 (상처 입은 치유자)
*   **콘텐츠:** 삶의 실천을 요구하는 '관계', '생활/사명', 깊은 '신학/교리' 카테고리 집중 배치. (예: 일터 영성, 재정관, 비윤리적 지시 대처, 이웃 사랑)
*   **가이드 톤앤매너:** 위로보다는 **'적용(Action Item)과 결단'** 중심.
*   **M12 완료 마일스톤 (연말 정산 & 재헌신):**
    *   *액션:* **1-Year Spiritual Wrapped (나의 1년 영적 여정 시각화 리포트)** 제공. 
    *   *메시지:* "올해 당신은 47번 '평안'을 묵상했고, 가장 많이 머문 곳은 '시편'이었습니다. 감정의 골짜기에서 시작해 사명의 산까지 올라오셨군요."
    *   *루프 완성:* 벅찬 감동을 준 직후, 새해 온보딩 화면을 띄워 "올해 당신의 새로운 영적 관심사는 무엇입니까?"를 다시 묻습니다. 1년 전 '우울'을 골랐던 유저가 1년 후 '이웃 사랑'을 고르는 스스로를 보며 완벽한 리텐션(2년 차 갱신)이 이루어집니다. 

이러한 세밀한 인터리빙 알고리즘과 장기 로드맵은 사용자에게 "이 앱이 내 영적 계절을 정확히 알고 완급을 조절해 주는 살아있는 목회자구나"라는 깊은 신뢰와 감동을 주게 될 것입니다.
